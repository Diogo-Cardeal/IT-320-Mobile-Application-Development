# Lesson 12 - Async Redux and Redux Persist

Expo SDK 54 React Native app for the Lesson 12 assignment.

## Run

```bash
npm install
npm run start
```

## Lint

```bash
npm run lint
```

The app fetches contacts from RandomUser, manages all shared data in Redux, uses Redux Thunk for async loading/success/error actions, and persists state with Redux Persist.
